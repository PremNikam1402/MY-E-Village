# E-Village Management System 🌐

A full-stack web application developed during my internship at ELIT Software. This project aims to digitize village administration and provide smart online services for rural communities.

## 🔗 Live Project
https://pr.interns-es3.co.in/

## 📌 Project Overview
The E-Village Management System is designed to modernize village services by digitizing records, improving accessibility, and simplifying administrative tasks through a secure web platform.

## ✨ Features
- Resident data management
- Digital village records
- Online service requests
- Secure authentication system
- Responsive UI for all devices
- Database-driven dynamic content

## ⚙ Installation

Clone repository:
```bash
git clone <your-repository-link>
```

Move to project folder:
```bash
cd E-Village
```

Install dependencies:
```bash
pip install -r requirements.txt
```

Run migrations:
```bash
python manage.py migrate
```

Start server:
```bash
python manage.py runserver
```

Open browser:
```bash
http://127.0.0.1:8000/
```
